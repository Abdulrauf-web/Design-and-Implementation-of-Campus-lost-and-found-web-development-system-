CampusFind – Campus Lost & Found Management System

About the Project

CampusFind is a web-based Lost and Found Management System designed to help students report, search for, and recover lost items within a tertiary institution.

The platform provides a simple way for students to report lost or found belongings and connect with the people who may have information about them.

Project Features

- Homepage with project information and statistics.
- Browse Lost and Found items.
- Report lost or found items.
- Upload pictures of reported items.
- Search items by name and description.
- Filter items by category and status.
- View detailed information about reported items.
- WhatsApp contact link for item owners or finders.
- Email and phone contact information.
- Responsive design for mobile phones, tablets, and computers.
- Local storage for saving submitted reports.

Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and responsive design.
- JavaScript – Functionality and interactivity.
- Browser Local Storage – Temporary local data storage.

How to Use

Download or clone the project.

Open the project folder in Visual Studio Code.

Open index.html using Live Server or a web browser.

Navigate to the Browse Items page to view reported items.

Use the Report Item page to submit a lost or found item.

Upload an item picture and provide the necessary details.

Browse the submitted items and contact the reporter through the available contact information.

Data Storage

CampusFind currently uses the browser's Local Storage to save submitted reports.

This means:

Reports remain available in the same browser and website origin.

Data is not automatically shared between different devices or browsers.

Clearing browser storage can delete saved reports.

The current version does not use a server-side database.

Project Scope

This version focuses on frontend development and demonstrates the basic operations of a campus Lost and Found platform.

Backend integration, database management, user authentication, and administrative management can be implemented in future versions.
